# TP_Labyrinth
Labyrinthe - Jeu de Parcours
Ce projet implémente un jeu de labyrinthe où le joueur explore un arbre d'intersections, résout des événements et cherche à atteindre la sortie. Le programme comprend plusieurs fonctionnalités comme la gestion des déplacements, l'affichage d'un labyrinthe et l'intégration d'événements spécifiques lors de la progression du joueur.

Description du projet
Le projet consiste à développer un jeu interactif dans lequel un joueur doit naviguer à travers un labyrinthe en explorant différentes intersections. Chaque intersection est représentée par un nœud d'un arbre binaire, avec des événements spécifiques pouvant se produire au fur et à mesure de l'avancement du joueur.

Le but du jeu est de se rendre à la sortie, représentée par un caractère 'S', en explorant de manière aléatoire un labyrinthe dont les événements sont générés de manière aléatoire pour offrir une rejouabilité.

Le jeu propose plusieurs modes :

Mode Mini : Pas d'événements dans le labyrinthe.
Mode Normal : Événements classiques dans le labyrinthe.
Mode Debug : Mode avec des informations supplémentaires pour aider au débogage.
Règles du labyrinthe : Affiche les règles du jeu, y compris la signification des lettres et symboles utilisés dans le labyrinthe.
Le joueur peut naviguer dans le labyrinthe à l'aide des touches directionnelles et peut choisir d'abandonner la partie à tout moment pour revenir au menu principal.
